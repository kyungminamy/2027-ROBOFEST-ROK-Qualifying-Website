# 작업 기록 (SESSION-LOG)

## 2027 ROBOFEST World Championship 국내예선대회 누리집

**이 문서는 "무슨 일이 있었는지"를 시간 순서로 적어 둔 기록입니다.**

Claude Code 는 대화를 기억하지 못합니다. 새 창을 열면 지난번에 무엇을 왜
했는지 하나도 모르는 상태에서 시작합니다. 그래서 매번 같은 설명을 다시
해야 하고, 이미 한 번 버린 방법을 또 제안하기도 합니다.

이 문서가 그 빈자리를 메웁니다. **세션을 시작할 때 맨 위 2~3개만 읽으면**
직전에 무슨 일이 있었는지 따라잡을 수 있습니다.

---

## ⚠️ 이 문서는 '규칙'이 아닙니다 ⚠️

규칙은 **`CLAUDE.md` 한 곳에만** 있습니다. 이 문서는 기록일 뿐입니다.

이 구분을 지키지 않으면 문서 두 개가 서로 다른 말을 하게 되고,
나중에 어느 쪽이 맞는지 아무도 알 수 없게 됩니다.

| | 어디에 적나 |
| --- | --- |
| "앞으로 항상 이렇게 해야 한다" (규칙) | **`CLAUDE.md`** 에 적습니다 |
| "이번에 이걸 이래서 이렇게 했다" (기록) | 이 문서에 적습니다 |
| 운영 절차 (날짜 바꾸기 등) | `docs/RUNBOOK.md` |

**새로 정한 규칙이 생기면 이 문서에만 적지 말고 반드시 `CLAUDE.md` 에도
옮겨 적으세요.** 이 문서는 시간이 지나면 아래로 밀려 아무도 읽지 않습니다.

## 쓰는 방법

### 세션을 시작할 때

Claude 에게 이렇게 말하세요.

```
docs/SESSION-LOG.md 의 맨 위 3개 항목과 CLAUDE.md 를 읽고 시작해 줘.
```

### 세션을 끝낼 때

일이 끝나면 Claude 에게 이렇게 말하세요.

```
오늘 한 일을 docs/SESSION-LOG.md 맨 위에 항목 하나로 추가해 줘.
양식은 그 문서에 있는 대로.
```

**새 항목은 맨 위에 넣습니다** (최신순). 아래로 갈수록 오래된 기록입니다.
지난 항목은 고치지 마세요. 틀린 것을 발견하면 새 항목에 "정정"으로 적습니다.

### 항목 양식

````markdown
## YYYY-MM-DD — 한 줄 제목

**남은 일**

**주의**
- 겪은 함정, 헷갈릴 만한 것. 없으면 "없음".

**커밋** `앞커밋..뒤커밋`
````
